# Cutter 1.0.1

Обновление: скачивание с видео-площадок, свой LLM-сервер, точная работа с моделями.

## Что нового

**Скачивание**
- **YouTube теперь реально качается** даже когда провайдер не резолвит `youtube.com`: приложение само переключается на DNS-over-HTTPS (Cloudflare / Google) и продолжает. Если в браузере открывается — тут тоже поедет.
- **Rutube и VK Видео** — вставляешь ссылку `rutube.ru/video/…`, `vk.com/video…`, `vkvideo.ru/…` и жмёшь «Скачать и нарезать». Публичные VK-ролики качаются без авторизации, закрытые дают понятную ошибку.
- Скорость: до 8 параллельных фрагментов, ретраи, без плейлистов.
- Кнопка «Скачать и нарезать» раньше не была подключена — теперь запускает скачивание (или Enter в поле ссылки).
- Live-стримы отсекаются с человеческим текстом («дождись окончания»).

**LLM**
- Шестой провайдер: **«Свой сервер (OpenAI /v1)»** — LM Studio, vLLM, Ollama, любые шлюзы. Указываешь `base_url` (по умолчанию `http://127.0.0.1:1234/v1`) и имя модели. Ключ необязателен: если сервер его не требует, `Authorization` не отправляется.
- Ошибка 404 подсказывает, что адрес, скорее всего, должен оканчиваться на `/v1`.

**Модели**
- Точные размеры файлов с ModelScope (например `medium` = 1.43 ГБ, а не «примерно 1500 МБ»).
- Проверка полноты после скачивания: недокачанная модель помечается «недокачана» и предлагается докачать.
- Кнопка **Удалить** модель — освободить диск.
- Прогресс показывает реальные байты.

**Мелочи**
- Папка результатов видна прямо на экране нарезки, клик открывает настройку.
- Прогресс больше не прыгает назад: скачивание занимает первые 18% шкалы, дальше нарезка.

## Установка

Скачай `Cutter-1.0.1-x64.msi` ниже → двойной клик. Ставится per-user без прав администратора,
ярлыки в меню Пуск и на рабочем столе, ffmpeg внутри.

Требования: Windows 10/11 x64, WebView2 Runtime (на современных сборках уже стоит).

## Проверено

- 169 офлайн-тестов (pytest), CI зелёный
- В реальной сети: YouTube probe 1.3 с + скачивание 534 КБ / 3.5 с; Rutube 6.7 МБ / 80 с; VK 2.5 МБ / 9.7 с
- Отмена скачивания на середине: файл не остаётся, резолвер восстанавливается
- Упакованное приложение v1.0.1: скачало YouTube через DoH, нарезка упала только из-за отсутствия модели whisper (ожидаемо на чистой установке)
