# Cutter 1.0.0

Локальное приложение: длинное видео → вертикальные шортсы с субтитрами, эффектами, музыкой
и загрузкой на площадки по кнопке.

## Установка

**MSI (рекомендуется):** скачай `Cutter-1.0.0-x64.msi` ниже → двойной клик → мастер установки.
Ставится в `Program Files\Cutter` (нужен UAC) или per-user без прав администратора.
Ярлыки появятся в меню Пуск и на рабочем столе. Размер 285 МБ, ffmpeg внутри.

**Требования:** Windows 10/11 x64. WebView2 Runtime — на современных сборках Windows уже стоит;
если окно не открывается, поставь «Microsoft Edge WebView2 Runtime» с сайта Microsoft.

## Что внутри

- Нарезка: ffmpeg + faster-whisper (локально) + LLM (DeepSeek / OpenRouter / Gemini / Groq / Ollama)
- Субтитры 4 стиля, вертикаль 1080×1920, блюр-фон
- Стиль кадра: Кино, Аура, Тёплый, VHS, Ч/Б
- Музыка: 8 оригинальных треков, сгенерированных процедурно, с авто-дакингом речи
- Защита от повторов: флип, микро-зум, скорость, зерно
- Метрики по клипам: скор, слова/минуту, эффект, музыка
- Скачивание YouTube по ссылке
- Загрузка: TikTok, YouTube Shorts, VK Клипы через Playwright; Dolphin Anty и AdsPower через CDP
- Режим тренировки — доводит до кнопки публикации и не нажимает

## Первый запуск

1. Настройки → Слух → скачай модель `medium` (или `small`, если диск/CPU скромные)
2. Настройки → Мозги → вставь ключ LLM и нажми «Проверить»
3. Нарезка → перетащи видео или вставь ссылку YouTube → «Нарезать»

## Честно

- Селекторы площадок не проверены на живых аккаунтах: сначала режим тренировки.
- Whisper на CPU: `medium` ≈ 1× реального времени.
- Права на исходный контент — на тебе. Бери то, где права улажены.

## Проверено

- 100 офлайн-тестов
- e2e по HTTP: файл → клипы → медиа отдаётся
- MSI: 36 PASS по установке/удалению/повторной установке без прав администратора
