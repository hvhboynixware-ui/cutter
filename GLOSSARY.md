# Cutter — GLOSSARY

Один термин — одно значение. Если в коде и в UI слова расходятся, прав код, а не UI.

| Термин | Значение | Слова-табу |
|---|---|---|
| **Job** | одна запущенная операция (нарезка, скачивание YouTube, загрузка на платформу). Живёт в очереди, отдаёт прогресс и логи | «таск», «процесс», «задача» |
| **Clip** | готовый вертикальный ролик 1080×1920 файлом `.mp4` + метаданные (title, hook, hashtags) | «шортс» в коде, «видео» |
| **Source** | исходник: локальный файл или YouTube-ссылка | «инпут», «материал» |
| **Moment** | выбранный LLM участок исходника (start/end + причина выбора) до рендера | «фрагмент», «секция» |
| **Profile** | профиль антидетект-браузера (Dolphin / AdsPower) или локальный persistent-профиль Playwright | «аккаунт» (аккаунт — это соцсеть, не браузер) |
| **Browser engine** | способ поднять браузер: `plain` (встроенный Playwright), `dolphin`, `adspower` | «антик», «браузер» без уточнения |
| **Platform** | соцсеть, куда грузим: `tiktok`, `youtube`, `vk` | «сервис», «сайт» |
| **Provider** | LLM-провайдер: `deepseek`, `openrouter`, `gemini`, `groq`, `ollama` | «модель» (модель — конкретный id внутри провайдера) |
| **Whisper size** | `tiny/base/small/medium/large-v3` — размер локальной модели распознавания | «версия» |
| **Style preset** | набор настроек субтитров и кадра: `classic`, `bold`, `clean`, `tiktok` | «тема» |
